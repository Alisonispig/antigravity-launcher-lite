Antigravity Launcher Lite 的首个正式版本。为已安装的 Antigravity 配置进程级 HTTP 代理、检测连接并启动客户端。

### 下载选择

| 系统 | 文件名中的标记 | 安装方式 |
| --- | --- | --- |
| macOS · Apple Silicon | `macos-arm64.dmg` | 打开 DMG，将应用拖入 Applications |
| macOS · Intel | `macos-x64.dmg` | 打开 DMG，将应用拖入 Applications |
| Windows · x64 | `windows-x64-setup.exe` | 运行 NSIS 安装器，默认仅安装到当前用户 |
| Linux · x86_64 | `linux-x64.deb` | 适用于 Ubuntu 22.04 及兼容环境，使用包管理器安装依赖 |
| Linux · x86_64 | `linux-x64.AppImage` | 赋予可执行权限后启动；仍受发行版图形栈、WebKitGTK/FUSE 等运行条件影响 |

macOS 另提供 `.app.zip` 应用压缩包。`SHA256SUMS.txt` 为下载文件校验值，`BUILD-METADATA.json` 记录构建提交、架构与各文件哈希。

### 主要功能

- 手动填写并验证 Antigravity 路径、HTTP 或混合代理端口。
- HTTP CONNECT 与 HTTPS 连通性检测，检测后启动客户端。
- 记住路径、代理、端口、语言和主题，重启自动恢复。
- 菜单栏/系统托盘驻留、窗口恢复与完全退出；macOS 关闭窗口时隐藏 Dock 图标。
- 中英界面、浅色/深色/跟随系统、原生标题栏配色同步及会话操作记录。

### 签名、依赖与验证范围

- macOS 采用 adhoc 本地签名，**没有 Developer ID 签名，也未经过苹果公证**。通过签名完整性检查不代表获得苹果信任；Gatekeeper 仍可能阻止运行。请按 [Apple 官方说明](https://support.apple.com/102445) 处理，项目不提供关闭安全保护的脚本。
- Windows 安装包未做 Authenticode 签名，可能出现 SmartScreen 提示。需要 WebView2；缺少运行时时，安装器会联网下载并安装。
- macOS 构建声明最低版本为 11.0，CI 使用 macOS 15；Windows 构建基于 Windows Server 2022，面向 Windows 10/11 x64；Linux 构建基于 Ubuntu 22.04。未在这些系统的所有最低版本上逐一验证。
- 三平台现有 CI 的类型检查、Clippy、核心测试与桌面编译已通过。发布流程另外检查包内架构、安装包结构及 CI 中的安装/启动观察。
- macOS Apple Silicon 已完成本机界面、配置保存、关闭/恢复与退出测试。维护者于 2026-11-04 确认多个平台使用测试通过，1.0.0 转为正式发布。CI 检查与维护者设备测试分别记录，不据此扩大最低系统版本兼容承诺。

### 使用前须知

需要先安装 Antigravity 并准备已有代理服务。请使用无认证的 HTTP 或混合端口；当前不支持 SOCKS-only、代理账号密码、自动发现或取消检测。

检测通过只表示能够经代理连接 `accounts.google.com`，不代表登录成功或所有客户端流量均采用代理。若 Antigravity 已运行，请先通过客户端菜单正常退出。

本应用为独立开发的非官方工具，非 Google 出品，不包含 Antigravity 本体或代理节点。完整说明见 [README](https://github.com/Alisonispig/antigravity-launcher-lite#readme)。
