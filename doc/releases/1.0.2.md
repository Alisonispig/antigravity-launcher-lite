Antigravity Launcher Lite 1.0.2 新增“启动后关闭本应用窗口”，让客户端启动后自动收起启动器。

### 本次更新

- 设置中新增“启动后关闭本应用窗口”开关，**默认开启**，升级后的已有配置也默认开启。
- 点击“检测并启动”，客户端通过早期退出观察后自动隐藏启动器窗口，继续保留菜单栏或系统托盘入口；macOS 同时隐藏 Dock 图标。
- 代理检测失败、客户端已运行或启动后很快退出时，窗口保持打开，方便查看提示。
- 可在设置中关闭此项，选择会自动保存。开关独立保存，不受尚未填完的代理输入影响。
- 窗口收起失败会单独提示，不会将已成功的客户端启动误报为失败。后台更新恢复不会额外收起用户正在查看的窗口。
- 保留 1.0.1 的客户端更新后恢复代理功能，该开关仍默认关闭。

### 下载与升级

| 系统 | 安装包 |
| --- | --- |
| macOS · Apple Silicon | `macos-arm64.dmg`，另附 `.app.zip` |
| macOS · Intel | `macos-x64.dmg`，另附 `.app.zip` |
| Windows · x64 | `windows-x64-setup.exe`，默认安装到当前用户 |
| Linux · x86_64 | `linux-x64.deb` / `linux-x64.AppImage` |

文件名前缀为 `Antigravity-Launcher-Lite_1.0.2_`。退出旧启动器后安装新版，原有路径、代理、语言和主题设置会保留。关闭启动器窗口后，从菜单栏或系统托盘选择“打开主窗口”即可恢复；选择“退出”才会完全结束启动器。

附 `SHA256SUMS.txt` 和 `BUILD-METADATA.json`，用于核对文件哈希、架构及构建提交。

### 验证与已知限制

本机已通过配置兼容性、默认值及关闭后持久化测试，以及前端类型检查、Rust fmt/Clippy。模拟 IPC 界面检查覆盖开关切换、页面重载恢复及中英文最小内容区域布局；不将模拟检查等同于真实客户端启动后隐藏窗口的端到端验收。

[三平台常规验证](https://github.com/Alisonispig/antigravity-launcher-lite/actions/runs/42547385657) 与 [四架构打包](https://github.com/Alisonispig/antigravity-launcher-lite/actions/runs/42547388440) 全部通过，包括原生安装包构建、版本/架构检查及安装/启动烟测。9 个附件已下载，与清单、构建元数据和 GitHub 资产 SHA-256 核对一致；两个 Mac 应用 ZIP 另通过签名完整性、版本和架构检查。构建提交：`5e5a53b578f3c646e0b1e5cc6003702799f0e793`。CI 启动烟测不等于所有系统版本和真实客户端流程的完整验收。

客户端更新后恢复代理仍只跟踪本次由启动器启动的会话。Linux 原生 Wayland、AppImage 临时挂载路径及更新后迁移安装目录尚不支持可靠的自动恢复；不响应正常关闭请求时会停止恢复，不强制结束进程。手动检测与启动功能仍保留。

### 签名与运行环境

macOS 为 adhoc 本地签名，未做 Developer ID 签名和苹果公证；Windows 未做 Authenticode 签名。系统可能出现提示，macOS 处理方式见 [Apple 官方帮助](https://support.apple.com/102445)。Windows 需要 WebView2，安装器会按需联网下载；Linux 仍依赖发行版图形栈、WebKitGTK/FUSE 等运行条件。

macOS 声明最低版本 11.0，构建环境为 macOS 15；Windows 使用 Windows Server 2022 构建，面向 Windows 10/11 x64；Linux 使用 Ubuntu 22.04 构建。不扩大最低系统版本兼容承诺。

本应用为独立开发的非官方工具，非 Google 出品。完整用法见 [README](https://github.com/Alisonispig/antigravity-launcher-lite#readme)。
