# 产品规划

更新时间：2026-11-04。项目暂名 Antigravity Launcher Lite。

## 目标与边界

提供轻量、可理解的 Antigravity 代理启动界面，覆盖 Windows、macOS、Linux。用户已安装 Antigravity，且已有可用的 HTTP/SOCKS5 代理。应用不提供节点、订阅、代理内核、账号服务或 OAuth 服务，不保证修复与代理无关的地区、账号、服务端和客户端故障。

安装后不要求用户安装 Rust、Node.js 或命令行开发工具。包大小和内存占用需要实测，不提前承诺固定数值。首版支持中文和英文，默认跟随系统语言，可手动切换。

## 首版 P0 功能

| 功能 | 计划行为与边界 |
| --- | --- |
| 客户端发现 | 扫描常见安装位置，验证可执行文件与应用信息；允许手动选择并记住路径 |
| 代理发现 | 保存的手动配置优先，其次系统静态代理、环境变量、常见本地端口；按来源展示候选，允许用户选择 |
| 协议识别 | HTTP CONNECT 与 SOCKS5 分别握手，区分 HTTP、SOCKS5、混合端口和无效服务；不只检查端口是否监听 |
| 连通性检测 | 经所选代理连接指定 HTTPS 目标，显示阶段、耗时与错误；不以单个目标成功宣称全部服务可用 |
| 手动代理 | 输入主机、端口、HTTP/SOCKS5 类型；首版不支持账号密码认证，发现需认证时明确提示 |
| 一键启动 | 校验客户端、检测代理、构造子进程环境、启动并监测早期退出；已有实例时引导正常退出 |
| 状态反馈 | 区分“进程已启动”“代理检测通过”和“应用实际联网待确认”，不把进程存在等同于 OAuth 成功 |
| 本地配置 | 保存客户端路径、代理端点、语言、主题和最近选择；损坏配置可恢复默认，写入需原子化 |
| 日志诊断 | 显示最近检测与启动事件；支持复制或导出脱敏诊断，导出前可预览 |
| 使用帮助 | 首次说明启动步骤，按平台展示安装、依赖与签名问题的处理文档 |

## 页面设计

默认使用系统标题栏和窗口按钮。单窗口，默认白色浅色主题，使用明亮彩色图标与点缀，支持明暗主题；不制作复杂导航、自绘窗口框架或动画背景。

根据 2026-11-04 体验调整，窗口内不出现滚动条；记录独立分页，帮助分为使用步骤与常见问题，不展示开发阶段或平台验收文案。关闭窗口后驻留托盘，macOS 隐藏 Dock 图标；通过托盘菜单恢复窗口或完全退出。平台验收状态保留在项目文档中。

首页从上到下：客户端路径与版本 → 当前代理和检测结果 → 主操作“检测并启动” → 可展开的诊断详情。路径和代理各提供一个编辑入口。检测期间显示当前步骤、取消按钮，避免重复启动。

设置页：自动/手动代理、客户端路径、语言、主题、日志保留和恢复默认。帮助页：平台安装说明、项目链接和版本信息。诊断面板展示时间、阶段、结果及可行动的建议，不默认显示底层堆栈。

典型流程：首次打开 → 发现客户端与代理 → 用户确认候选 → 检测并启动 → 显示启动结果。后续打开复用已选配置，但启动前重新验证。

## 后续 P1

- 托盘/菜单栏快捷启动（托盘驻留、窗口恢复与完全退出已提前实现）。
- 多个代理配置档案、最近检测结果、快捷重试。
- 手动检查新版本，浏览器打开官方 Releases；自动安装更新另行评估签名与维护成本。
- 原生 keychain/凭据管理器集成后再支持代理认证，禁止把密码放在 JSON 配置中。
- PAC、桌面环境和打包版 Antigravity 的兼容扩展，根据实际反馈安排。

## 首版不做

代理订阅管理、TUN、全局系统代理切换、账号登录/切换、token 提取、自动修补 Antigravity 文件、开机启动、自动结束进程、沙箱绕过、远端控制、自动更新安装。
